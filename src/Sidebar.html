How to use it

  • =IBAN_VALID(A2:A100) TRUE or FALSE
  • =IBAN_ERROR(A2:A100) why an IBAN failed
  • =IBAN_BANK(A2:A100) the bank's name
  • =IBAN_BIC(A2:A100) the bank's BIC
  • =IBAN_CHECK(A2:A100) all five columns

For a long list, select the IBANs and use Check selected IBANs in the add-on menu: the results are written as values next to them and are not recalculated.

Each IBAN counts as one request on your key. Results are kept for six hours in your own Google account, so the same IBAN checked again within six hours is not counted.
